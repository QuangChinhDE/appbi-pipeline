# Intent: <feature>

Keep this short. If it takes more than a page, the task is too big.

## Problem

What is wrong or missing today. Observable, not hypothetical.

## Value

Who benefits and how. One or two sentences.

## Expected outcome

What is true when this is done, from a user's point of view.

## Constraints

Versions, deployments, compatibility, deadlines, anything fixed.

## Out of scope

Named explicitly. This is the section that stops a feature sprawling.

## Acceptance criteria

Every criterion names the check that proves it. A criterion with no check is
not accepted; `manual:` needs a reason it cannot be automated.
